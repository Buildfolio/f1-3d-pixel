# โมเดล 3D Pixel รถแข่ง F1 ครบ 11 ทีม

เว็บแอปไฟล์เดียวสำหรับสำรวจรถแข่ง F1 แบบ 3D Voxel Pixel ครบทั้ง 11 ทีมในฤดูกาล 2026 — หมุนชมรอบคัน 360° และแยกดูโครงสร้างทีละชิ้นส่วน

## เปิดใช้งาน

เปิดไฟล์ `index.html` ในเบราว์เซอร์ได้เลย (ต้องต่ออินเทอร์เน็ต เพราะโหลดไลบรารี Three.js จาก CDN) ไม่ต้องติดตั้งอะไรเพิ่ม

## ทำอะไรได้บ้าง

- **เลือกทีม** — เปลี่ยนสีรถ (livery) ครบ 11 ทีม แต่ละทีมมีสีตัวถัง ปีก จมูก Halo ชุดนักขับ และหมวกกันน็อกของตัวเอง
- **กริดครบ 11 ทีม** — โหมดดูรถทั้ง 11 คันจอดเรียงบนพื้นสนาม คลิกที่รถคันไหนเพื่อเจาะลึกทีมนั้น
- **หมุน-ซูม 360°** — ลากหมุน เลื่อนลูกกลิ้งซูม พร้อมมุมกล้องสำเร็จรูป 6 แบบ (รอบคัน / ด้านหน้า / ด้านข้าง / ห้องนักขับ / ด้านหลัง)
- **แยกดูชิ้นส่วน (Exploded View)** — เลื่อนสไลเดอร์แยกชิ้นส่วนรถออกทีละส่วน (ปีกหน้า จมูก ไซด์พอด ฝาเครื่อง ห้องนักขับ ปีกหลัง ล้อ ช่วงล่าง)
- **องศาเลี้ยวล้อหน้า & พวงมาลัย** — ปรับ -22° ถึง +22° ล้อหน้ากับพวงมาลัยหมุนตาม
- **จำลองการทำงาน** — หมุนโชว์รอบคันอัตโนมัติ, หมุนล้อจำลองความเร็ว, เปิดแผ่นปีกหลัง DRS, แสดง/ซ่อนพื้นสนามแข่ง 3D Pixel
- **ไฮไลต์ชุดประกอบ** — คลิกเลือกดูเฉพาะส่วน (ปีกหน้า & จมูกรถ, ห้องนักขับ & Halo, ไซด์พอด & ฝาเครื่อง, ปีกหลัง DRS, ล้อ & ช่วงล่าง)

## เทคโนโลยี

- HTML + CSS + JavaScript ไฟล์เดียว (`index.html` ~75 KB)
- [Three.js r128](https://cdnjs.cloudflare.com/ajax/libs/three.js/r128/three.min.js) ผ่าน CDN — เรนเดอร์ WebGL แบบเรียลไทม์
- รถแต่ละคันสร้างจาก voxel (ลูกบาศก์ 3D pixel) บนกริดจำนวนเต็ม — ชิ้นส่วนหลัก (พื้นรถ จมูก ปีกหน้า ไซด์พอด ฝาเครื่อง ห้องนักขับ ปีกหลัง ช่วงล่าง ล้อ) มี blueprint แยกกัน แล้วประกอบด้วย InstancedMesh
- ไม่ต้อง build ไม่ต้องใช้เซิร์ฟเวอร์

## ที่มา

โปรเจกต์ทดลองทำเว็บ 3D แบบไฟล์เดียว — เริ่มจากอยากดูรถ F1 ทั้ง 11 ทีมฤดูกาล 2026 (ปีแรกที่มี Audi กับ Cadillac) ในรูปแบบ pixel art 3 มิติที่หมุนดูได้จริง
